# Mission Reflection

## 1. Which cloud platform impressed you the most?

GCP impressed me the most because it has the best tools for AI and machine learning. I like that it offers Google Kubernetes Engine (GKE) which is the best Kubernetes service. GCP also has BigQuery for data analytics which is very powerful and fast. Google's global network backbone makes it reliable and fast.

---

## 2. What similarities exist among AWS, Azure, and GCP?

All three cloud platforms offer the same core services like compute, storage, networking, and identity management. They all have global infrastructure with multiple regions worldwide. Each platform provides virtual machines, object storage, and IAM for access control. They all have free tiers and pay-as-you-go pricing models.

---

## 3. How do business requirements influence cloud platform selection?

Business requirements are the main factor in choosing a cloud platform. If a company already uses Microsoft products, Azure is the best choice because it integrates well. If a company focuses on AI and data analytics, GCP is better. If a company needs the broadest range of services, AWS is the best option. The decision depends on what the company needs and what they already have.

---

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that cloud decisions are not just about technology but also about business needs. A cloud engineer must understand the client's goals, budget, and existing infrastructure before recommending a solution. I also learned that each cloud platform has its own strengths and weaknesses. Being a consultant means matching the right tool to the right problem.
