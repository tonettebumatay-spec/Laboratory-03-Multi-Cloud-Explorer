# Client Recommendations

## Client A – Startup Company

**Recommendation:** AWS

**Explanation:** AWS is ideal for startups because it has a generous free tier, startup credits program (AWS Activate), and the broadest range of services to support rapid growth. It offers the most flexibility for building cloud-native applications from scratch.

**Three Services:**
- Amazon EC2 (virtual machines for hosting)
- Amazon S3 (storage for user data)
- AWS Lambda (serverless for backend APIs)

---

## Client B – University

**Recommendation:** Azure

**Explanation:** Since the university already uses Windows Server, Microsoft 365, and Active Directory, Azure is the natural choice because it integrates natively with these Microsoft technologies. This provides single sign-on, unified billing, and built-in compliance.

**Three Services:**
- Azure Virtual Machines (for Windows Server workloads)
- Azure Active Directory (identity management)
- Azure Blob Storage (for student records and data)

---

## Client C – AI Research Company

**Recommendation:** GCP

**Explanation:** GCP is the strongest platform for AI and machine learning with tools like Vertex AI and BigQuery. It offers high-performance computing and is built on Google's infrastructure designed for data-intensive workloads.

**Three Services:**
- Google Compute Engine (high-performance VMs)
- Vertex AI (machine learning platform)
- BigQuery (data analytics)

---

## Client D – Global E-Commerce Company

**Recommendation:** AWS

**Explanation:** AWS offers the most mature global infrastructure with 34 regions and extensive services for high availability and auto-scaling. It has the broadest set of tools for global web applications, including content delivery and load balancing.

**Three Services:**
- Amazon EC2 Auto Scaling (automatic scaling)
- Amazon CloudFront (content delivery)
- Elastic Load Balancing (traffic distribution)

---

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
| :--- | :--- | :--- |
| Startup Company | AWS | Free tier, startup credits, broadest services for growth |
| Enterprise Organization | AWS | Mature platform, most services, largest ecosystem |
| Microsoft Environment | Azure | Seamless integration with Microsoft products |
| AI / Machine Learning | GCP | Best-in-class AI/ML tools and BigQuery |
| Kubernetes Deployment | GCP | Best-in-class GKE, built on Google's container expertise |
| Global Web Application | AWS | Most mature global infrastructure and CDN services |
