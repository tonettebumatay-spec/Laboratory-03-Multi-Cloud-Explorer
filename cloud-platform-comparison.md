## Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services with over 200 services covering compute, storage, databases, analytics, AI/ML, and more. It has the most mature ecosystem and deepest feature set.

**2. Which provider best integrates with Microsoft technologies?**
Azure best integrates with Microsoft technologies including Microsoft 365, Active Directory, Windows Server, and Teams. It is the default choice for organizations already using Microsoft products.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
GCP is strongest in AI/ML with tools like Vertex AI and Gemini, and offers best-in-class Kubernetes (GKE). Google's internal infrastructure gives it an edge in data and AI workloads.

**4. Which cloud platform would you personally choose and why?**
 I would personally choose GCP because I am interested in AI and machine learning. GCP has the best tools for data analytics and Kubernetes.
